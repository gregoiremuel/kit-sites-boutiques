# Modèle de rapport mensuel (une page)

Pour le palier 0, à recopier dans un document d'une page. Pour le palier 1, `rapport.html` est fabriqué par `node outils/visibilite-google.mjs preparer <fiche.json>` avec exactement ces rubriques (à imprimer ou à enregistrer en PDF depuis le navigateur).

**Règle** : seuls les chiffres relevés dans la fiche Google, la Search Console ou la page de modification du site vont dans le rapport. L'IA n'écrit aucun chiffre. Un chiffre introuvable s'écrit « non disponible », jamais 0.

---

## [Nom du commerce]
Visibilité Google, rapport de [mois année]

### Les chiffres du mois
| Indicateur | [mois précédent] | [mois] | Écart |
|---|---|---|---|
| Appels depuis la fiche (Fiche Google) | | | |
| Demandes d'itinéraire (Fiche Google) | | | |
| Clics vers le site depuis la fiche (Fiche Google) | | | |
| Affichages de la fiche, recherche et Maps (Fiche Google) | | | |
| Pages vues du site (page de modification, sans cookie ; seulement si le client a un site) | | | |

Écart : « +7 », « −5 » ou « stable ». Aucun pourcentage, aucune note sur 100.

### Ce qui a été fait
- 3 à 6 lignes, des faits vérifiables : « Horaires des jours fériés de novembre mis à jour », « 2 photos de la vitrine ajoutées (envoyées par vous) », « 1 post publié le 12 après votre accord », « 2 réponses aux avis publiées ».

### Les avis
Note actuelle : [x,y] sur [n] avis. [n] nouveaux avis ce mois-ci, [n] avec une réponse publiée.

### Prévu le mois prochain
- 2 à 4 lignes, par exemple : « Annoncer [fait donné par vous] », « Mettre à jour vos fermetures de [mois] », « Demander cinq photos de produits ».

### À savoir
Je ne promets aucune place dans Google. Je promets un travail fait chaque mois, que je vous montre ici. Les appels et les demandes d'itinéraire sont les premiers chiffres à regarder ; je ne peux pas dire à l'avance dans quel délai ils évoluent. Rien n'est publié sans votre accord.

## Pour toi, avant d'envoyer
- Chaque chiffre est recopié de l'écran de la fiche (capture gardée dans le dossier du client).
- Un mois sans validation du client est écrit tel quel : « pas de validation ce mois-ci, mises à jour factuelles seulement ».
- Trois mois sans mouvement : regarde d'abord la fiche (catégorie, horaires, photos, avis sans réponse) avant de toucher au site.
- Le rapport n'est pas un argument de vente : ne compare jamais deux clients entre eux.
